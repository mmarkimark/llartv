## Specs

- S1 #69 (owner, verbatim): "Posar una dita, quote of de day o algo així que si motivadora o que faci pensar. S'hauria de buscar algun lloc on hi hagi frases d'aquest tipus en anglés, castellà i català." Owner decisions: type = "Barreja de les dues" (traditional sayings with no author, plus quotes by classic authors); place = "Home, tot el dia" (a discreet line under the date, visible all day).
- S2 #69 design (parent, from research L2): quotes are bundled in the app, one file per language (assets/quotes/ca.tsv, es.tsv, en.tsv), one line per quote: `text<TAB>author<TAB>source` (author empty for a traditional saying; source = the Wikiquote/Wikisource page it was checked against). 366 lines per language, roughly half sayings and half author quotes. Authors must have died before 1956 (public domain in the EU, life + 70). No modern copyrighted quotes. The day's quote = line (day-of-year − 1) of the interface-language file; same quote all day, changes at midnight; follows the interface language. Home shows it under the date (max two lines, then the author as "— Author"), night palette applied. A settings on/off row `quote` (default on, home.conf key `quote=on|off`, empty restores default, removed by reset), localised ca/es/en. Licence of the compiled files documented in docs/quotes.md and credited in README (Wikiquote content is CC BY-SA 4.0).
- S3 #70 (owner, verbatim): "pel que fa a la part de temps, hauria de posar la ciutat o d'on l'agafa." Owner decision: "location_name + font" — optional home.conf key `location_name` (default "Barcelona", matching the default `location`); the weather card shows "<location_name> · Open-Meteo" (just "Open-Meteo" when empty). Documented, kept by ADB configuration, removed by reset. No reverse geocoding or new request.
- S4 Cross-cutting: tests with the behaviour, docs (README configuration table, CHANGELOG [Unreleased]), screenshots in English where the README shows Home, no new dependency.

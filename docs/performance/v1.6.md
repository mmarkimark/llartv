# LlarTV v1.6 performance (emulator, paired)

**Status: the emulator paired check is inside every allowance; the reference-TV check is still open.** v1.6 adds a
quote of the day, the weather place and source, and a minimal mode. Emulator numbers are a regression guard, not a
substitute for the [physical-TV release gate](baseline-v1.0.md#targets).

## Setup

- Target: Android TV emulator `emulator-5554`, AOSP TV on x86, Android 11 (SDK 30), same fixture for both versions
  (Bing wallpaper, default dock, Catalan interface); the configuration was written again after every install.
- Baseline: [published v1.5 APK](https://github.com/mmarkimark/llartv/releases/download/v1.5/LlarTV.apk),
  4,149,623 bytes.
- Candidate: feature branch through the v1.6 work units, debug APK, 4,266,909 bytes (+117,286 bytes, +2.83%; the
  three quote files add about 351 KB of text), same signing certificate, installed in place with `install -r -d`.
  An earlier incremental build of the same tree measured 4,326,621 bytes: 60 KB of stale dex, not a real change. The
  release APK is the one built from `main` (a clean worktree), and its bytecode is identical to the measured build.
- Procedure: `scripts/measure.sh --serial emulator-5554 --apk <apk> --runs 5` (one discarded warm-up, five cold
  starts, five returns from another app, three PSS samples), after a 20 s settle following each install. Two
  alternating rounds: baseline, candidate, baseline, candidate.

weather, news, quote, wallpaper, screensaver photos or music, the football card or the photo-tinted dock. Measured on
the emulator (5 cold starts × 2, alternating): normal 586 604 580 575 616 / 588 615 596 633 595 ms (median ~596 ms)
against minimal 438 442 433 455 475 / 454 443 440 467 482 ms (median ~449 ms, −25%); TOTAL PSS after 20 s: 42,033 KB
normal against 34,188 KB minimal.
